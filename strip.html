Segments

The strip is split into blocks of LEDs that each take one colour. "Show segments" lights them alternately red and blue, with segment 1 white, so you can count them. If your count differs, change the number above.

Command finder

The H617C is close to the H617A, but some commands may differ. Tap each test and watch the strip, then tell Claude which ones worked.
