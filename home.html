Alexa buttons

Buttons on the dashboard that run an Alexa Routine or make your Echos announce something. They go through Voice Monkey, a free Alexa skill:

  1. Sign up at voicemonkey.io and enable the Voice Monkey skill in the Alexa app.
  2. In the Voice Monkey console, add a Routine Trigger for each button (or a Speaker for announcements) and copy its ID.
  3. In the Alexa app, make a Routine. For When this happens, pick the Voice Monkey device and that trigger. Add any actions, such as Customised, where you type a command exactly as you'd say it.
  4. Paste your Voice Monkey API token below, then add a button with the trigger's ID.

Lights

Each light takes one Bluetooth connection at a time, so while this screen is connected your phone can't be. Tap the light's switch off here, or close this screen, before using the phone remote.

To reconnect by itself after the page reloads, open chrome://flags, search for Web Bluetooth new permissions backend, turn it on and restart Chrome.
